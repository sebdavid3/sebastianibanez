## 00 // CONCEPTUAL FRAMEWORK
This portfolio is a fusion of **Swiss Typographic Minimalism** and **90s Cyberpunk / Retro-Anime** aesthetics (inspired by *Ghost in the Shell* and *Neon Genesis Evangelion*). It is designed not just as a website, but as a high-density functional terminal interface.

## 01 // CORE IDENTITY
I am a Software Engineer and Systems Engineering student at **Universidad del Norte**. I view software as a dynamic ecosystem, focusing on the "why" behind every development.

- **Focus:** Backend Engineering, System Architecture, Scalability.
- **Specialization:** Modernizing legacy systems, Biometric Authentication APIs, Distributed Computing.
- **Stack:** Java (Spring Boot), Python, AWS, Docker, Next.js.

## 02 // TECHNICAL SPECIFICATIONS
- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router).
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (High-performance engine).
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (Glitch effects, Boot sequence).
- **Icons:** [Lucide React](https://lucide.dev/).
- **Vibe:** Deep Black (#050505), Unit-01 Purple (#A855F7), Neon Green (#52d053).

## 03 // INTERFACE FEATURES
- **System Boot Sequence:** Real-time CLI log simulation on initialization.
- **Classified Archives:** Projects displayed as technical mission files with RGB-split glitch effects.
- **CLI Progress Bar:** Dynamic retro loading indicator under the main header.
- **Technical HUD:** Fixed frame with real-time synchronization (Bogota time zone) and geospatial coordinates (Barranquilla, CO).
- **Verification Vault:** Integrated DataCamp certification tracking with direct uplink verification.

## 04 // OPERATIONAL INSTRUCTIONS
To run this terminal locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sebdavid3/sebastianibanez.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Initiate system:**
   ```bash
   npm run dev
   ```
4. **Access UI:** `http://localhost:3000`
