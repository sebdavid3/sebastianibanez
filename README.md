## 00 // CONCEPTUAL FRAMEWORK
This portfolio is a fusion of **Swiss Typographic Minimalism** and **90s Cyberpunk / Retro-Anime** aesthetics (inspired by *Ghost in the Shell* and *Neon Genesis Evangelion*). It is designed not just as a website, but as a high-density functional terminal interface.

## 01 // CORE IDENTITY
I am a Software Engineer and Systems Engineering student at **Universidad del Norte**. I view software as a dynamic ecosystem, focusing on the "why" behind every development and optimizing the interaction between complex systems.

- **Experience:** Currently modernizing legacy Java applications and architecting biometric authentication APIs at Security Systems S.A.S.
- **Focus:** Backend Engineering, System Architecture, Scalability, Cloud Native solutions.
- **Stack:** Java (Spring Boot), Python, AWS, Docker, Next.js, SQL Server, DynamoDB.

## 02 // TECHNICAL SPECIFICATIONS
- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router).
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (High-performance engine).
- **Email Service:** [Resend API](https://resend.com/) for functional technical transmissions.
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (Glitch effects, Retro CLI progress bars).
- **Performance:** Optimized image handling via `next/image` and high-performance transparency layers.

## 03 // INTERFACE FEATURES
- **System Boot Sequence:** Real-time CLI log simulation on initialization.
- **Classified Archives:** Projects displayed as technical mission files with functional repository uplinks.
- **CLI Progress Bar:** Dynamic retro block-loading indicator (`████░░`) synced with system state.
- **Technical HUD:** Fixed frame with real-time Synchronization (Bogota time zone) and geospatial coordinates (Barranquilla, CO).
- **Verification Vault:** Integrated DataCamp certification tracking with direct uplink verification.
- **Functional Uplink:** Secure contact form integrated with automated email delivery protocol.

## 04 // OPERATIONAL INSTRUCTIONS
To run this terminal locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sebdavid3/sebastianibanez.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure Environment:** Create a `.env.local` file with your `RESEND_API_KEY`.
4. **Initiate system:**
   ```bash
   npm run dev
   ```
5. **Access UI:** `http://localhost:3000`
